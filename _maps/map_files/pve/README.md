# PvE: выживание

В лобби выберите режим **PvE Survival** (`pve`) через административную панель смены режима. Арена загружается автоматически. Обычная карта станции отдельно для запуска PvE не выбирается.

Игроки появляются в левой части коридора, противники — в правой. Все участники получают гражданскую роль, биту, нож, рюкзак, бинты и 100 кредитов. Позднее подключение также ведёт на арену с этим комплектом. Снаряжение для дыхания выдаётся по обычным правилам вида персонажа.

Перед первой волной и после каждой победы есть минута подготовки. Противники выходят по одному раз в две секунды; следующая волна ждёт полного уничтожения предыдущей. Размер волны зависит от числа выживших и её номера, максимум — 60 противников. С каждой волной растут здоровье и урон, с третьей появляются быстрые враги, с пятой — тяжёлые. В каждой пятой волне есть вожак.

За волну N каждый выживший получает `100 + 25 × N` кредитов и `100 × N` очков. Баланс связан с разумом персонажа и сохраняется при переподключении. В магазинах слева доступны лечение, броня, оружие, боеприпасы и комплекты турелей. Лазерное оружие можно заряжать у левой стены.

Комплект турели используется в руке на свободном месте и развёртывается за три секунды. Турель работает без внешнего питания и стреляет только по противникам волн; её пули не повреждают союзников. Противники могут уничтожить турель.

Волны бесконечны. Когда погибают все участники, раунд заканчивается и выводятся личные очки. Автоматических возрождений нет. Станционные случайные события отключены, эвакуация блокируется на время режима.

Баланс — начальный вариант для игровых испытаний. Таймеры и параметры волн находятся в `code/game/gamemodes/pve/pve.dm`, цены — в `code/game/gamemodes/pve/pve_equipment.dm`.
