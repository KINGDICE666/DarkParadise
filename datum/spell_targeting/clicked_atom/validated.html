choose_targetsLike /datum/spell_targeting/clicked_atom, but only returns the clicked atom if the spell considers it a valid target (spell.valid_target). This lets a pointed spell reject a misclick (empty space / scenery) BEFORE perform() runs - so no invocation, sound, or cooldown is spent.
