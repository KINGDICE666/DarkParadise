# НТрнет: первый этап

API с MariaDB и входом по одноразовому коду реализован на этапе 2:
см. [services/ntrnet](../../services/ntrnet/README.md). Этот каталог сохраняет
заглушку и демонстрационные данные для независимой проверки первого этапа.

Реализованы локальная API-заглушка, зоны `.ss13` и `.ss13dp`, каталог,
просмотр страниц и переходы между сайтами из PDA. Приложение выключено
по умолчанию. База данных, авторизация игроков, редактор, HTML/CSS-санитайзер,
медиа/R2, поиск, дельты и развёртывание на VDS относятся к следующим этапам.
Заглушка предназначена только для локальной разработки и слушает loopback.

## Локальный запуск

Python 3.11+, сторонних библиотек нет. Из корня репозитория в PowerShell:

```powershell
$env:NTRNET_SERVER_KEY = [guid]::NewGuid().ToString('N')
python tools/ntrnet/stub.py
```

До запуска скопируйте значение переменной в локальный `config/config.txt`:

```text
NTRNET_ENABLED 1
NTRNET_API_URL http://127.0.0.1:8091
NTRNET_SERVER_KEY <значение переменной NTRNET_SERVER_KEY>
```

URL задаётся без завершающего `/` и без `/api/v1`. Для реального сервиса
используется HTTPS. Локальный конфиг исключён из Git. Никогда не размещайте
рабочий ключ в примерах, исходниках, changelog или тестовых данных.

Соберите TGUI и игру, затем запустите локальный мир:

```powershell
./tgui/bin/tgui.bat --mode=production
& 'C:/Program Files (x86)/BYOND/bin/dm.exe' paradise.dme
```

В PDA с указанным владельцем появится «НТрнет». Откройте оба сайта,
перейдите между страницами, остановите API и убедитесь, что уже загруженные
страницы остаются доступны. При выключенном `NTRNET_ENABLED` или отсутствии
URL/ключа приложение скрыто и запросы не отправляются. Конфиг применяется
при запуске мира.

## Контракт `/api/v1`

Все игровые маршруты требуют `X-Server-Key`; ключ видит только игровой
сервер. В TGUI он не передаётся. Содержимое этих запросов не записывается
штатным HTTP-логгером. Ответы имеют `Cache-Control: no-store` и
`X-Robots-Tag: noindex, nofollow`.

| GET | Ответ |
| --- | --- |
| `/health` | Состояние заглушки, без авторизации |
| `/api/v1/zones` | `{ "zones": [{ "name": "ss13", "server_id": null, "active": true }] }` |
| `/api/v1/catalog` | `{ "sites": [{ "id", "domain", "title", "version", "pages": [{ "slug", "title" }] }] }` |
| `/api/v1/sites/{id}/pages/{slug}` | `{ "site_id", "slug", "title", "version", "tree" }` |

`id`, `slug` и `version` — строки. Первая страница сайта — главная.
Сервер задаёт порядок каталога и страниц. При изменении любой страницы
или списка страниц нужно изменить `version` сайта. Исчезнувший из каталога
сайт становится недоступен, его кэш удаляется. Опциональный `hidden: true`
в fixture исключает сайт и из каталога, и из маршрутов страниц.

Заглушка читает `sites.json` при запуске. После изменения fixture перезапустите
её. Общая зона имеет `server_id: null`, зона Dark Paradise — `dark-paradise`.
Это тестовые записи; постоянные зоны в MariaDB появятся с настоящим API.

## Дерево страницы

Текст: `{ "type": "text", "text": "Текст" }`.
Контейнер: `{ "type": "p", "children": [...] }`.
Внутренняя ссылка: `{ "type": "link", "site_id": "welcome", "slug": "index", "children": [...] }`.

Поддерживаются `div`, `p`, `span`, `h1`–`h4`, `strong`, `em`, `u`, `s`,
`ul`, `ol`, `li`, `blockquote`, `pre`, `code`, `br`, `hr`.
Неизвестные типы пропускаются вместе с их содержимым. Атрибуты из JSON
никогда не распространяются на DOM. HTML-строки, CSS, произвольные `href`,
скрипты и внешние ресурсы не поддерживаются. `link` вызывает игровое действие,
которое проверяет наличие целевой страницы в каталоге.

Визуализатор ограничен глубиной 16 и 1024 узлами. Игровой клиент принимает
ответ страницы до 64 КиБ и каталога до 512 КиБ, максимум 500 сайтов по
20 страниц. Это временный предел полного индекса до реализации дельт
и пагинации. Кэш содержит до 32 страниц, общих для всех PDA. Одновременно
выполняются максимум четыре запроса страниц и один запрос каталога.
Каталог обновляется не чаще раза в пять минут; повторы неудачной загрузки
страницы — не чаще раза в 30 секунд. Ошибки и некорректные ответы не стирают
последний успешно загруженный каталог.

Формат v1 расширяется добавлением полей и типов; существующие типы сохраняют
значение. Это начальный контракт, а не завершённая переносимая интеграция:
до предложения PR другим серверам нужно закончить авторизацию и медиа.

## Проверки

```powershell
python -m unittest discover -s tools/ntrnet -v
```

Тесты интерфейса: из `tgui` выполнить
`node .yarn/releases/yarn-4.8.1.cjs jest --runInBand NtrnetDocument`.
DM-проверки ответов и кэша включены в общий набор `UNIT_TESTS`.

Следующий этап — настоящий API с MariaDB и одноразовыми кодами на 15 минут,
привязанными к подтверждённому `ckey` и зарегистрированному серверу.

  локальных define проходят. Полные проверки дубликатов и unticked files
  находят старые копии DM-файлов в локальной `data/fit-independent-review`

ещё не выполнены. Игровая конфигурация и секреты не изменялись.
